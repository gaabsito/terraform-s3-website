Infraestructura como Código (IaC)

¿Qué es Terraform?

Terraform es una herramienta de código abierto desarrollada por HashiCorp que permite definir, aprovisionar y gestionar infraestructura física y en la nube de forma declarativa. En lugar de configurar servidores de forma manual, Terraform utiliza el lenguaje declarativo HCL (HashiCorp Configuration Language) para describir el estado final deseado de la arquitectura.

✔
Plan y Aplicación: Permite previsualizar los cambios de infraestructura antes de aplicarlos para evitar errores catastróficos.
✔
Multi-Cloud: Soporta proveedores líderes de la industria como AWS, Azure, Google Cloud y más mediante proveedores estandarizados.
Almacenamiento y Hosting de Objetos

¿Qué es AWS S3?

Amazon Simple Storage Service (S3) es un servicio de almacenamiento de objetos líder en la industria, que ofrece una escalabilidad, disponibilidad de datos, seguridad y rendimiento líderes del sector. Es una pieza fundamental en cualquier ecosistema DevOps gracias a su versatilidad.

✔
Hosting Web Estático: Permite servir archivos HTML, CSS y JS de forma global, rápida y con costes ínfimos sin necesidad de configurar servidores web complejos.
✔
Durabilidad Extrema: Diseñado con una durabilidad del 99.999999999% (11 nueves) de los datos de manera nativa y automática.
Protocolo de Contexto de Modelos (MCP)

¿Qué es Model Context Protocol?

El Model Context Protocol (MCP) es un estándar abierto que define de qué forma un modelo de Inteligencia Artificial (LLM) se conecta a fuentes de datos y herramientas externas. Actúa de manera idéntica a una interfaz USB para modelos de lenguaje, permitiendo una comunicación segura y estructurada.

✔
Seguridad y Orquestación: Permite que agentes inteligentes como este lean e interactúen de forma segura con recursos de tu entorno de desarrollo o servidores, sin que la IA tenga libre acceso descontrolado.
✔
